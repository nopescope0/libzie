> Belgeler `docs/` altında: `docs/PRODUCT.md`, `docs/DESIGN.md`, `docs/ROADMAP.md` (kökte yalnızca README, LICENSE, CLAUDE.md ve kod durur).

## Overview

"libzie" (formerly "Ders Arşivi") — a local-only web app for organizing course materials (PDFs, slides). Code comments are in Turkish; the UI is available in Turkish and English (see "Diller (i18n)" below). Every user-facing string goes through an ID in `static/lang/<dil>.json` — never hard-code UI text in `index.html`/`server.py`.

No dependencies, no build step, no tests, no linter: Python standard library on the backend, a single vanilla HTML/CSS/JS file on the frontend.

## Running

```bash
python server.py               # serves http://127.0.0.1:8765 and opens the browser
python server.py --no-browser  # same, without opening a browser (used by .claude/launch.json)
```

End users get the packaged Windows app (installer / portable exe, see "Masaüstü uygulaması" below); `baslat.bat` is only a local, untracked (gitignored) demo launcher kept by the maintainer. `PORT` env var overrides the port (useful when 8765 is already taken by the user's own running instance — don't kill it; test on another port with a scratch copy of the project so the user's real files aren't touched).

The content folder defaults to `./kaynaklar`. It can be changed from the in-app Ayarlar dialog (writes the gitignored `ayarlar.json`, applied immediately without a restart; see `ayarlar.ornek.json`) or pinned with the `KAYNAK_KLASORU` env var (which locks the dialog) — intended for a Google Drive folder that Notability auto-backs-up PDFs into. If the configured folder doesn't exist at startup (e.g. Drive not mounted) the server falls back to `./kaynaklar` and `/api/tree` returns a `warning` that the UI shows as a banner; it never creates the configured path.

## Architecture

- **`server.py`** — `ThreadingHTTPServer` bound to `127.0.0.1` only. The filesystem is the database: the content root (`ROOT`, default `kaynaklar/`, gitignored) holds the user's files, and its folder hierarchy *is* the course/folder structure. There is no metadata store, so files added via Explorer show up automatically.
  - `GET /api/tree` returns the whole nested tree (`{name, path, folders[], files[]}`); hidden entries (dot-prefixed) are skipped.
  - `GET /files/<path>` serves files inline, with single-range `Range` support (206/416) so pdf.js and the browser's PDF viewer can read big files in chunks; a `?v=<mtime>` query is ignored server-side and only busts client caches. `GET /vendor/<name>` serves vendored third-party files from `static/vendor/` (pdf.js 3.11.174 `pdf.min.js`/`pdf.worker.min.js` from cdnjs, Apache-2.0; the Linux Libertine OTFs) — flat filenames only.
  - `POST /api/upload?dir=&name=` takes the **raw file bytes as the request body** (not multipart; the `cgi` module is gone in Python 3.13+). Name collisions get ` (2)`, ` (3)`… suffixes via `unique()`.
  - `POST /api/mkdir|move|delete|open|reveal` take JSON bodies. `move` handles both rename and relocate (`{from, dir, name?}`). `delete` is a soft delete into `kaynaklar/.silinenler/` and returns the `trash` name; `POST /api/restore {trash, to}` moves it back (appends " (2)" on a name clash, `clean_name`/`safe` guarded) and powers the "Geri al" toast. `GET /api/preview?path=` reports `{exists, courses, files, capped}` for the Ayarlar folder preview (read-only, skips dot entries, caps at 20k files). `open`/`reveal` launch the OS default app / file explorer (needed because browsers can't render .pptx/.docx).
  - Every client-supplied path must go through `safe()` (resolves and rejects anything outside `ROOT`) and every new name through `clean_name()`. Errors are returned as `{"error": "..."}` with status 400 and shown as toasts by the frontend.
- **Güvenlik (2026-10, sertleştirme turu):** `server.py` her istekte sırayla `guard()` (Host ∈ 127.0.0.1/localhost/[::1]:port → DNS rebinding; `Sec-Fetch-Site` same-origin/none; POST'ta `Origin` eşleşmesi + `X-Libzie: 1` özel başlığı → CSRF) ve `authorized()` (oturum anahtarı çerezi `libzie_k`) uygular; yalnızca `/api/ping` anahtarsızdır. Anahtar `%APPDATA%\libzie\oturum.key` içindedir ve **her sunucu başlangıcında yenilenir** (`start()` → `new_token()`; `LIBZIE_OTURUM_DOSYASI` yalnızca test için); `/?k=<anahtar>` ile ilk açılışta oturum çerezine (`libzie_k_<port>`, HttpOnly, SameSite=Strict, `Max-Age` yok) çevrilir (`launch_url()`; `app.py` ve `server.main` bunu kullanır). Çalışan örneğe bağlanmadan önce `is_libzie()` rastgele sayıyla `/api/ping?n=` çağırır ve yanıttaki `proof` (= HMAC-SHA256(anahtar, n)) doğrulanmazsa karşıdakine güvenmez ve anahtarı göndermez (port işgali). Sunucu `Server` sınıfıyla `SO_EXCLUSIVEADDRUSE` kullanır (Windows'ta başka bir sürecin aynı porta ortak bağlanıp bağlantıları çalmasını engeller). Yazma işlemleri `check_write()` (sistem/Başlangıç/`%APPDATA%\libzie`/`%LOCALAPPDATA%\Programs` klasörlerine yazılamaz) ve yükleme/yeniden adlandırmada `check_ext()` (`BLOCKED_EXT`: exe, bat, ps1, lnk… eklenemez) ile korunur; `OPEN_OK`'ta `svg` yoktur. **Geliştirirken** `preview_start`/tarayıcıyı `http://127.0.0.1:8765/` ile açmak 401 verir: `?k=<anahtar dosyasındaki değer>` ile aç (çerez kalır). Tüm istemci `fetch` POST'ları `X-Libzie: 1` göndermeli (`api()` ve yükleme zaten gönderiyor; yeni POST ekleyince unutma). `/files/` PDF dışı her şeyi `Content-Security-Policy: sandbox` ile sunar (kullanıcı klasörüne düşen SVG/HTML betik çalıştıramaz); uygulama sayfası `CSP_APP` ile (eval yok, `connect-src` yalnızca self + Open-Meteo); pdf.js `isEvalSupported: false` (CVE-2024-4367). `/api/open` yalnızca `OPEN_OK` izin listesindeki uzantıları açar (yürütülebilir türler "Klasörde göster"e yönlenir); `clean_name()` Windows ayrılmış adlarını ve sondaki noktayı reddeder; JSON gövdesi 1 MB ile sınırlı; ders rengi sunucuda `#hex` olarak doğrulanır ve istemcide `colorOf()` yine süzer. Yeni bir endpoint eklerken bu zinciri atlama; yeni bir dış alan adı gerekiyorsa `CSP_APP`'e ekle. İş akışı (`windows.yml`): derleme işi salt okur, yayın yetkisi yalnızca `yayinla` işinde; action'lar commit SHA'sına sabit (Dependabot günceller); etiket adı `env` ile aktarılır; her sürüme `SHA256SUMS.txt` eklenir. Bkz. `SECURITY.md`.
- **`guncelleme.py`** — uygulama içi güncelleme (Ayarlar → Güncelleme). `VERSION` burada tutulur; GitHub Actions derlemede etiketten (`v0.1.3` → `0.1.3`) bu satırı yeniden yazar, elle artırmaya gerek yok. `check()` GitHub `releases/latest`'i okur (sürüm yoksa/depo gizliyse 404 → "Yayınlanmış bir sürüm bulunamadı"). `kind()`: paketlenmişse ve exe'nin yanında `unins000.exe` varsa `kurulum`, yoksa `tasinabilir`, paketlenmemişse `kaynak` (güncelleme uygulanmaz). `start_apply()` arka plan iş parçacığında asset'i (`libzie-kurulum.exe` / `libzie-tasinabilir.exe`) temp'e indirir (boyut + MZ + **zorunlu** sha256 doğrulaması: GitHub'ın asset `digest` alanı, yoksa sürümdeki `SHA256SUMS.txt`, ikisi de yoksa güncelleme reddedilir; adres yalnızca bu deponun `releases/download/` yolundan, istemciden URL alınmaz), sonra `kurulum` için sihirbazı `/SILENT /CLOSEAPPLICATIONS` ile, `tasinabilir` için gizli konsollu bir `degistir.bat`'ı başlatır (exe kilidi açılana kadar `move /y` dener, sonra yeni exe'yi başlatır) ve 1,5 sn sonra `os._exit`. Başlatılan süreçlere PyInstaller'ın `_PYI*`/`_MEIPASS2` ortam değişkenleri geçirilmez (yoksa yeni tek dosya exe silinmiş geçici klasörü arar). Sihirbaz sessizken `libzie.iss` uygulamayı yeniden açar (`Check: WizardSilent`). `LIBZIE_GUNCELLEME_URL` ortam değişkeni sürüm adresini sahte bir sunucuya çevirir (yalnızca deneme için). Endpoint'ler: `GET /api/update/check|status`, `POST /api/update/apply|settings`; `ayarlar.json` anahtarları `otomatik_guncelleme` ve `son_otomatik_deneme` (açılışta otomatik güncelleme her sürümü yalnızca bir kez dener, başarısız olursa döngüye girmez). Arayüz: `static/index.html` içinde "güncelleme" bloğu (`initUpdate`, `checkUpdate`, `pollUpdate`, `autoUpdate`; açılıştan 4 sn sonra çalışır).
- **`static/index.html`** — the entire frontend. State is the fetched `tree`, the current folder `cur` (kept in the URL hash, `#/<encoded path>`), and the search `query`; `render()` redraws the sidebar tree, breadcrumbs and content from that state. The tree is re-fetched after every mutation and on window focus. Paths are always `/`-separated and relative to `kaynaklar/`.
  - Search uses `norm()` to fold Turkish characters/diacritics so "isletim" matches "İşletim". The search box (`#q`) lives in the top bar; the `/` / Ctrl+K shortcut first leaves the file view because the top bar is hidden there. The sidebar slot under the brand is a plain HH:MM clock (`#clock`, `renderClock()` every second, blinking separator, full date in its tooltip); it deliberately uses a 4px radius instead of `var(--r)`. The brand has an inline SVG logo (`.brand-logo`): three leaning books on a shelf spelling "lib" (the "i" book's dot `.logo-dot` is a stroke-less accent-filled circle). The side books' ±8° lean lives in CSS (`.logo-l`/`.logo-b`, `transform-origin` at their bottom corners in SVG units), not in SVG `transform` attributes, so the hover `topple-l`/`topple-b` animation (stand upright → topple back with slight overshoot, "b" delayed) can override it. Coordinates were chosen so the 1.3-stroke books touch without overlapping at rest. Next to the clock, `#weather` shows an outline condition icon (`weatherIcon()` → `W_ICONS`, grouped by WMO code; parts carry `wi-*` classes for slow looping CSS animations — rays spin, clouds drift, drops/flakes fall with staggered `--d` delays, bolt flickers; falling parts start at opacity 0, so the reduced-motion rule forces them visible) + current temperature + today's expected condition from Open-Meteo (no API key; WMO codes mapped to Turkish in `WMO`). The city is typed by the user (geocoded via Open-Meteo, saved as `weatherPlace`); browser geolocation is intentionally not used. Results are cached 30 min in `localStorage` (`weather`) and the last value is shown offline — this is the app's only outbound network call, so keep it optional.
  - The home greeting is split into per-letter spans for its hover animation (staggered `letter-wave`); "i"/"İ" are rendered as dotless "ı"/"I" plus an absolutely positioned "˙" (`.tittle`) so the dot can hop on its own. The tittle offsets (`.02em`, `-.13em`) were measured for Linux Libertine — re-measure if the font changes. The plain text is kept in `aria-label`. The same animation auto-plays once per page load (`.hi.play`, guarded by `greetPlayed`, delayed .35s to follow the content entrance, class removed afterwards so hover still works); the window-focus reload is skipped for the first 3s after boot (`bootAt`) so it can't re-render the greeting mid-animation.  - Drag-and-drop distinguishes internal moves (custom `application/x-ders-yol` data type) from OS file drops (`Files`). Dropped folders are walked via `webkitGetAsEntry`, preserving their structure.
  - Extensions in `VIEWABLE` open in the in-page iframe viewer; anything else is sent to `/api/open`.
  - Folder/file context menus are shared between the `⋯` buttons and right-click: `menu(anchor, items, pos)` / `folderMenu()` / `onRightClick()`; pass `pos` for cursor placement. `ask()` resolves from its own button handlers rather than the `<dialog>` `close` event (that event doesn't fire reliably in the embedded Browser pane, so don't build flows on it).
  - Opened files live in tabs above the content area (`tabs`, `active`; `active === null` means the file browser). One `<iframe>` per tab is created lazily and hidden/shown, never recreated, so PDF scroll position survives tab switches. `syncTabs()` runs after every `load()` to prune tabs for deleted files and bump the iframe's `?v=<mtime>` when the file changed on disk (Notability re-backups); `afterMove()` remaps tab paths. Any folder navigation or search resets `active` to `null`.
  - Viewer space is deliberately maximized: while a file is open (`main.viewing`) the top bar is hidden and the tab bar (`#tabbar`: tabs + "open in default program" + sidebar toggle) is the only chrome; iframes load with `#view=FitH&navpanes=0`. The sidebar collapses via `body.side-collapsed` (`--side-w` var, Ctrl+B, persisted as `sidebar`).
  - Meaningful motion (state/continuity/feedback) lives in the "hareket: süreklilik ve geri bildirim" block: `transition(update, nameOld, nameNew)` wraps View Transitions — home tile ⇄ course page (`go()` uses `history.pushState` + synchronous `render()` inside the transition; tile shape `vt-shape` flies to the breadcrumb course icon, tile `vt-tile` zooms/blurs out) and thumbnail/row → viewer (`vt-doc`). It always falls back to a plain update when unsupported, under reduced motion, or if the update callback hasn't run within 400ms (frozen/background windows), and swallows aborted-transition promise rejections. Feedback: `arrivals` (paths added by upload/rename/move get `.arrive` on their next render, cleared in `load()`), `flashAccept(dir)` on a successful drop, `leave(path)` fades items before delete (capped at 260ms, returns an undo for failures), and `toast(msg, err, stay, progress)` draws a progress bar. Cards, rows, tiles and tree nodes carry `data-path` for this.
  - Motion values use the transitions.dev token scale declared in `:root` (`--duration-*`, `--ease-*`, `--distance-*`, `--scale-*`, `--blur-*`; `--ease` is kept as an alias of `--ease-smooth-out`). Pick tokens by what the motion does, not the nearest number: opens slower than closes (sidebar 400/350, toast 250/350, menus/dialogs open 250), hover-ins ≤250ms with no delay on hover-out, stagger 40ms with ≤300ms total, emphasis moments 500ms. Deliberately off-scale: continuous loops (weather icons, clock, upload arrow), the logo topple and greeting tittle hop, the 600ms thumbnail zoom (user-requested), and the greeting wave's 12×40ms total. JS-driven `leave()` uses literal token values (150ms, smooth-out).
  - Animations are CSS-driven and gated: `render()` adds `#content.enter` only when `animateNav` was set (folder navigation via `go()`/`hashchange`, or returning from a file view), never on focus-triggered reloads or uploads. `renderTabs()` rebuilds the tab bar only when the tab list/colors change so the active-underline transition runs in place; PDF iframes crossfade through the `.on` class (not `hidden`). Everything collapses under `prefers-reduced-motion`.
  - UI palette is navy + orange by default (dark theme). **Colors are not in `index.html` anymore:** they live in `static/themes/<id>.json` (see "Temalar" below) and reach the CSS as `:root` variables (`--bg`, `--side`, `--surface`, `--hover`, `--line`, `--line-strong`, `--shelf`, `--text`, `--muted`, `--faint`, `--accent`, `--highlight`, `--highlight-hover`, `--on-accent`, `--danger`, `--warn`, `--shadow`, `--scrim`, `--t-pdf/slide/doc/sheet/img`). Use the vars, never literal colors, and use `color-mix(in srgb, var(--accent) N%, transparent)` for translucent tints. Theme-independent constants only: the thumbnail glass buttons (`--glass*`, defined in `:root` of `index.html`), the `rgba(0,0,0,.18)` hover overlay on course-colored tiles, and the course `PALETTE`/ink colors in JS.
  - Design language (modelled on jackywinter.com's landing grid): flat solid-color blocks, sharp corners, 5px dark gaps, thin outline shapes, large regular-weight serif type. Keep to it: every `border-radius` uses `var(--r)` (2px), grid gaps use `var(--gap)`, two font roles, both from the Linux Libertine 5.3.0 release (GPL+font exception / SIL OFL, OTFs in `static/vendor/` + `LinLibertine-OFL-1.1.txt`, downloaded from the official SourceForge release; `@font-face` prefers a Windows-installed copy via `local()`): `var(--font-head)` = Linux Libertine (serif) only for headings — `h2`, `.brand`, the greeting, the clock and the weather temperature (one selector list next to the `button, input` reset); `var(--font)` = Linux Biolinum (its sans companion) for everything else, including course names, because the serif looked harsh at small sizes. Section headings are large sentence-case, not small uppercase labels.
  - Courses render as solid-color tiles (`courseTile(f, index)`): on the home page as large tiles plus a trailing "Yeni ders" tile, inside a course as `.tiles.small` for subfolders. Tile background is the course color darkened 15% and text color is picked by luminance (`tileColors()`); the same pair (`tileVars()` → `--tile`/`--ink`) fills the active tab and the active sidebar node. Sidebar course rows have no hover background: a `::before` in the course color is clipped by a 5-point `clip-path` polygon that morphs hidden → small left triangle (hover) → full row (active). Because `renderTree()` rebuilds the list every render, rows are built with the previous selection (`treeActive`) and then flipped to `cur` after a forced reflow, so the fill/drain transition actually plays. Shapes come from `SHAPES` by alphabetical index so siblings get distinct shapes; hover swaps the shape for file count/last-modified + arrow.
  - Folder file listings default to a thumbnail grid (`fileView`, toggle persisted as `view`; search results and "Son açılanlar" stay list rows). PDF first pages are rendered lazily with pdf.js (`IntersectionObserver`, max 2 concurrent, `buildThumb`) and cached as JPEG blobs in IndexedDB keyed by `path|mtime|size`; images use themselves; other types show an extension badge. `fileMenu()` is shared by rows and cards.
  - Accessibility/usability pass (from the critique): text on a course color is chosen by WCAG contrast in `tileColors()` (tries `INK_DARK`/`INK_LIGHT`, nudges the tile bg the least needed to reach 4.5:1) — never reintroduce a luminance cutoff. Every `.tile/.tcard/.row/#tree .node/.tab` is a focus stop (`tabindex=0`, roles, `aria-*`); one delegated keydown handler gives Enter/Space = click, arrows via `neighbor()` (geometry-based), F2 = rename, Delete = remove, and only fires when the element itself (not its inner ⋯/× button) is focused. `:focus-visible` ring + `:focus-within .more` keep the hover-only ⋯ reachable. `toast(msg, err, stay, progress, action)` takes `{label, fn}` for "Geri al" (delete → `/api/restore`, move → move back). Inside a course the course chip is hidden (`courseBadge()`), the files heading is "<course> dosyaları", search is scoped to the current course (`searchAll` toggle) and the breadcrumb keeps the path; subfolders inside a course use the compact `.tiles.small`; the home page shows courses as books on a shelf (see Motif below). Weather icon loops run only on hover/focus, the clock separator is static, and `.paused` (set on `visibilitychange`) freezes every animation while the tab is hidden.
  - `localStorage` (wrapped in try/catch via `store`) only holds per-browser conveniences: recently opened files, expanded sidebar nodes, and the open tabs.
  - Critique pass (2026-10): home order is greeting (38px) → "Devam et" (4 most recent files, from `recent`) → "Dersler". ## Temalar (2026-10)

- **Dosyalar:** `static/themes/<kimlik>.json` = `{ "scheme": "dark" | "light", "vars": { "--bg": "#0e1a2b", ... } }`. Varsayılan tema `navy` (koyu şemalı lacivert-turuncu; `temalar.DEFAULT`) her zaman bulunmalıdır; öteki temalarda eksik değişkenler onunkilerden gelir. Görünen adlar dil dosyalarında `theme.<kimlik>` (ve `theme.auto`).
- **Sunucu (`temalar.py`):** dosyaları doğrular ve CSS'e çevirir. Yalnızca `ALLOWED` değişken adları ve yalnızca renk değerleri (`#hex`, `rgb()`, `hsl()`) kabul edilir; geçersiz tema atlanır (stderr uyarısı). Böylece bir tema dosyası sayfaya başka CSS, dış kaynak ya da `</style>` sokamaz. `Handler.send_index()` CSS'i `<style id="themes">` (`/*THEMES*/`), `[{id, scheme}]` listesini `<script id="themes-data">` (`/*THEMES_JSON*/`) içine gömer. Varsayılan tema ayrıca `:root`'a, her tema `.theme-prev[data-theme]` önizleme kartlarına uygulanır; kaydırma çubuğu okları (veri adresi CSS değişkeni alamaz) her temanın `--accent` renginden üretilir.
- **İstemci:** `<html data-theme="...">` etkin temayı seçer; `<head>` içindeki küçük betik ilk boyamadan önce uygular (yanıp sönme yok), ana betikteki "tema" bloğu (`applyTheme`, `setTheme`, `buildThemePane`) seçimi yönetir. Seçim `localStorage` `theme` = `auto` (varsayılan; sistemin `prefers-color-scheme` tercihini canlı izler) | tema kimliği; bilinmeyen değer `auto`'ya düşer. `<meta name="theme-color">` etkin `--bg` ile güncellenir. Ayarlar → Tema: önizlemeli kartlar (`role="radio"`, ←/→ ile gezilir).
- **Yeni tema eklemek:** `static/themes/<kimlik>.json` oluştur (kimlik `[a-z][a-z0-9_-]{1,23}`), `theme.<kimlik>` adını `tr.json`/`en.json`'a ekle, `python tools/tema_kontrol.py` (WCAG kontrastları: metin ≥7, soluk/küçük metin ve düğme ≥4,5) ve `python tools/i18n_kontrol.py` çalıştır, gözle kontrol et (ana sayfa, ders sayfası, ayarlar, menüler). Yeni bir renk değişkeni gerekirse `temalar.ALLOWED`, `dark.json` (ve `tema_kontrol.py` `CHECKS`) güncellenir.
- Yol haritasında: kullanıcıya özel temalar (`%APPDATA%\libzie	hemes`).

## Sistem tepsisi (2026-10)

- **`tepsi.py`:** `Tray` sınıfı, ek bağımlılık olmadan ctypes ile `Shell_NotifyIconW` simgesi (kendi iş parçacığında gizli üst düzey pencere + ileti döngüsü). Sol/çift tık → `on_show`, sağ tık → menü (Aç, Güncellemeleri denetle [`on_update` verilmişse], Çıkış; dil `lang()` ile her açılışta okunur; `app.py` güncelleme maddesinde pencereyi gösterip `openSettings('about')` çalıştırır, Hakkında sekmesi denetimi başlatır), `WM_CLOSE`/`WM_ENDSESSION` → `on_quit` (kurulum sihirbazı/oturum kapanışı), `TaskbarCreated` → simge geri konur (Gezgin yeniden başlarsa). `remove()` simgeyi eşzamanlı siler (`os._exit` öncesi hayalet simge kalmasın), `stop()` iş parçacığını kapatır, `balloon()` kısa bildirim verir. Simge: paketlenmişte exe'nin kendi simgesi (`ExtractIconW`), kaynak koddan `assets/icon.ico`. Windows dışında `start()` False döner.
- **`app.py`:** tepsi başarıyla kurulduysa `window.events.closing` işleyicisi, "Pencereyi kapatınca arka planda çalış" seçeneği açıkken (`server.tray_enabled()`, `ayarlar.json` `arka_planda`, varsayılan açık) pencereyi **gizler** ve kapatmayı iptal eder (pywebview: işleyici `False` dönerse iptal); gerçek çıkış tepsi menüsünden `quit_app()` ile. İlk gizlemede bir kez balon ipucu (`tray_ipucu`). İkinci başlatma: `server.start()` çalışan örneğe bağlanıyorsa `server.request_show(url)` onu öne getirir (`POST /api/desktop/show`, `DESKTOP_HOOKS["show"]`) ve çıkar; çalışan örnek masaüstü değilse (`DESKTOP` False) eskisi gibi yeni pencere açılır. Güncelleme `os._exit` yapmadan önce `guncelleme.EXIT_HOOKS` (tepsi simgesini silme) çalışır.
- **Ayarlar:** `POST /api/settings/general { tray?, lang? }` (`GET /api/settings` → `desktop`, `tray`). Dil, tepsi menüsü de aynı dili kullansın diye sunucuda (`dil`) tutulur; `auto` ise `tepsi.system_lang()` (Windows arayüz dili). Genel sekmesindeki kutu masaüstü dışında devre dışıdır.
- **Test:** pywebview takip edilemediği için akış sahte bir `webview` modülüyle (closing/hide/show/destroy) ve tepsi API düzeyinde (`Shell_NotifyIconGetRect`, `PostMessageW`) sınandı; gerçek pencerede ilk deneme CI'da derlenen exe ile yapılır.

## Ayarlar penceresi (2026-10)

- `<dialog id="settings">` büyük ve sekmelidir (880x640): solda dikey `role="tablist"` (`.set-nav`: Genel, Tema, Kaynak yolu, Hakkında), sağda seçili sekmenin `role="tabpanel"` paneli (`.set-pane[data-pane]`). Pencerenin kapatma düğmesi sağ üst `#s-cancel` (×) ve Esc'tir; "Kaydet" yalnızca Kaynak yolu sekmesindeki yol içindir (dil ve otomatik güncelleme anında kaydedilir).

Kenar çubuğundaki dişli (`#open-settings svg`, ad `vt-gear`) ekranın ortasına uçup büyür (pencerenin içindeki `#set-gear`, yalnızca geçiş sırasında `.vt-arriving`/`.vt-closing` ile görünür), pencere (`vt-dialog`) dişlinin sönmesiyle birlikte ölçek+solma ile açılır; kapanırken solarak küçülür, dişli belirip simgeye döner. Süreler token ölçeğinden (transitions-polish): açılış `--duration-very-slow` 500ms (dişli uçuşu `--duration-fast` 250ms, dişli varınca sönerken pencere yerinde `--scale-large`+`--blur-small`+solma ile belirir; **dairesel `clip-path` maskesi kullanma**: dişlinin arkasında bir "çember" gibi görünüyordu), kapanış daha hızlı ve sessiz `--duration-medium` 350ms (bulanıklık yok), ease `--ease-smooth-out`. Dişliye hareket bulanıklığı eklidir (`vt-gear-blur-up/down`, `--blur-small`: hız arttıkça artar, varışta tepe yapar, sonra netleşir; ince çizgi için daha fazlası hâleye dönüşür). Dişli uçarken `rotate` ile dönerek hızlanır (`vt-gear-spin-up`: varış anında ~4600°/sn (900° toplam), sonra yavaşlar; kapanışta `vt-gear-spin-down` hızlı başlayıp simgeye yavaşlayarak oturur). **Pencerenin kendi `pop` animasyonu** (`dialog[open]`) geçişle açılınca `#settings.vt-open` ile kapalı tutulur (kapanana dek); sınıf kalkarsa pop yeniden başlayıp pencereyi ikinci kez açar. Anahtar kareler `:root.vt-set-open`/`:root.vt-set-close` altında (`vt-dialog-open/close`, `vt-gear-arrive/depart`), süreler `--duration-very-slow` çarpanlarıdır. `showSettingsDialog()`/`closeSettingsDialog()` kullanılır; Esc (`cancel` olayı), × ve **pencerenin dışına (karartılmış alana) tıklamak** da animasyonlu kapatır (basış da dışarıda başlamalı: metin seçerken fareyi dışarıda bırakmak kapatmaz), kaydet ise anında kapatır (ardından sayfa yeniden çizilir). Destek yok/hareket azaltılmış/400 ms içinde kare çıkmazsa düz açılır.

## Diller (i18n, 2026-10)

- **Dosyalar:** `static/lang/<dil>.json` (`tr.json` varsayılan/yedek, `en.json`). Düz `{kimlik: metin}`; `"_name"` dilin kendi adı (dil seçicide görünür). Kimlikler noktalı ve anlamlıdır (`menu`/`file.open_default`, `err.exists`, `upd.err.offline`, `wmo.95`, `icon.atom`). Çoğul değer `{ "one": ..., "other": ... }` nesnesidir (istemci `Intl.PluralRules` ile seçer, `vars.n`); yer tutucular `{ad}`. Yeni dil = `static/lang/` altına yeni dosya (dil seçici ve algılama sözlükteki dillerden otomatik kurulur).
- **Yükleme:** `i18n.py` dosyaları okur; `Handler.send_index()` ana sayfadaki `/*I18N*/` yerine tüm sözlükleri `<script type="application/json" id="i18n-data">` içine gömer (ek istek/gecikme yok, `<` kaçırılır). Kaynak koddan çalışırken sözlük her istekte yeniden okunur; paketlenmişte bir kez.
- **İstemci (`static/index.html`, "diller (i18n)" bloğu):** `t('kimlik', { değişken })` etkin dil → `FALLBACK` (`tr`) → kimliğin kendisi. Statik HTML'de `data-i` (metin), `data-i-title`, `data-i-ph`, `data-i-aria`, `data-i-html` (değeri HTML içerebilen güvenilir metinler); `applyI18n()` hepsini çevirir. HTML'deki Türkçe metin yalnızca JS çalışmadan önceki yedektir. Dil: `localStorage` `lang` = `auto` (varsayılan: `navigator.language` bir sözlük diliyse o, değilse `en`) | dil kodu; Ayarlar'da `#s-lang`. `setLang()` statik metni ve dinamik içeriği (`render()`, hava durumu, güncelleme mesajı `showUpd()`) yeniler. Tarih/sayı biçimi `locale()`/`lang`'e göre. JS'te yerel değişkeni `t` diye adlandırma: çeviri işlevini gölgeler (sekmeler için `tb`).
- **Sunucu hataları:** metin yerine kimlik taşır: `raise AppError("err.exists")`, `AppError("err.folder_missing", path=str(p))`, güncelleme için `UpdateError("upd.err.offline")` (ikisi de `i18n.AppError`; `UpdateError` `guncelleme.py`'de). Yanıt `{"error": Türkçe varsayılan, "code": kimlik, "vars": {...}}`; istemci `errText(j)` ile etkin dilde gösterir (kimlik sözlükte yoksa `error`). Güncelleme durumu `error_code`/`error_vars`, kök klasör uyarısı `warning_code`/`warning_vars` taşır. 401/403 sayfaları (`deny("http.no_access")`) "Türkçe / English" iki dillidir. GET hataları da JSON döner (`AppError` → 400; yalnızca `err.bad_path` 403).
- **Yeni metin eklerken:** önce `tr.json`'a kimlik + Türkçe metin, sonra `en.json`'a karşılığı (yer tutucular aynı olmalı), kodda yalnızca kimliği kullan. **`python tools/i18n_kontrol.py` çalıştır**: kodda kullanılıp sözlükte olmayan, bir dilde eksik, yer tutucusu uyuşmayan kimlikleri ve kullanılmayanları bildirir (hata varsa çıkış kodu 1).
- Kurulum sihirbazı (`libzie.iss`) Türkçe + İngilizce; yerleşik `{cm:...}` metinlerini kullanır.
